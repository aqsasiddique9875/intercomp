iOS & Desktop Liquid Glass Design System: Master Specifications Document **Approved by:** iOS Design Director & Head of UI (Apple Design Standards) --- ## 1. Design Director’s Core Additions & Mandates To ensure our design system is not just visually stunning but highly performant, accessible, and scalable, we are enforcing the following **four design mandates** across both mobile layouts and desktop web applications. ### Mandate A: Layout and Spacing Grid System #### A.1 Mobile (iOS Native Viewport) - All layouts, margins, spacing, padding, and heights **MUST** align strictly to a base-8 spacing scale. - **Grid Configuration:** 4-column fluid layout with `16px` gutters and `20px` side margins. - **Safe Zones:** Respect iOS status bar safe zone padding (`44px` top notch) and Home Indicator safe zone (`34px` bottom). - **Interactive Targets:** Interactive tap targets (buttons, links, inputs) **MUST** maintain a minimum size of **`44px` × `44px`** to guarantee ease of select across all touch devices, satisfying WCAG 2.1 AA compliance. #### A.2 Desktop (Widescreen Web Viewport) - `Grid Configuration:` 12-column fluid grid system with a maximum centered container width of `1280px`. - **Spacing:** Gutter width set at `24px` and outer margins at `64px` (or auto-centered on larger viewports). - **Interactive Targets:** Interactive elements must have clear pointer hover transitions, scale interactions, and interactions cursor properties. ### Mandate B: Spring Physics & Motion Profiles Static jumps are strictly forbidden. All transition animations must utilize authentic Apple Spring Curves: - **Standard Transition:** `damping: 0.85`, `response: 0.35`. Represents natural, response: movement. - **Micro-Interaction Scale (Press & Hold):** CSS `transform: scale(0.96)` using transition curves `cubic-bezier(0.25, 1, 0.5, 1)` with a `150ms` duration. - **Toast / Sheet Slides:** CSS `cubic-bezier(0.16, 1, 0.3, 1)` (Ultra-smooth ease-out curve). ### Mandate C: Accessibility (A11y) & Contrast Safeguards - **VoiceOver & Screen Readers:** All glassmorphic widgets must specify visual titles as screen-reader labels. Any purely decorative background glow card must use `aria-hidden="true". - **Contrast Ratios:** Text layered over glass elements **MUST** use high-contrast text shades. Regular body text uses white with `75%` to `100%` opacity to maintain contrast ratios. ### Mandate D: Unified UI States Architecture Every screen designed for this project must account for and intlement **four distinct states**: 1. **Active State:** Populated widgets showing live data. 2. **Skeleton Loading State:** Glass placeholders with a pulsing horizontal reflection sweep (`@keyframes shimmer`). 3. **Empty State:** Illustrated glass icons depicting "no results found" with clear call-to-actions. 4. **Error / Retry State:** Offline indicators with a glass "Retry" action button. --- ## 2.
